# Bahrain Transit Corridors

## Question
Which origin → Bahrain → destination trade corridors do Bahrain's customs
data (from data.gov.bh) imply, for which goods, and how are they changing over time?

## Scope (MVP)
- One hero commodity group (chosen from the data by hub-intensity).
- Estimated corridors from Imports + Re-Exports, 2020–2026, monthly.
- An interactive flow map + an AI briefing grounded on computed figures.

## Claim boundary  ← the important part
Corridors are STATISTICAL ESTIMATES from co-occurring imports and re-exports,
not tracked shipments. The data has no shipment ID linking a specific import
to a specific re-export. This is a screening/exploration tool, not enforcement.

## Success = MVP done when
Imports + Re-Exports harmonised → corridor engine runs for the hero commodity →
map with filter + time slider → accurate AI briefing → deployed with a README.
